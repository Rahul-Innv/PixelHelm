## candidate-1

Direction intent (written before any code existed): "A page from the shop's printed seed annual: every variety is one numbered catalogue entry set in warm type, read by the fire the way gardeners have always read winter seed lists."

Declared convention breaks (per the pre-registration's Amendment A1, these and ONLY these are the candidate's deliberate breaks; any other convention break you find is undeclared and scores as a mistake, not a signature):
- No card, panel, or photo-tile chrome anywhere — the catalog is set as a printed seed-annual list: numbered entries, rules, catalogue typography on a paper ground (breaks the marketplace card convention; the printed annual is the form gardeners already trust). The money path inside each entry stays fully conventional.
- Botanical specimen labels — each variety's botanical/type line is set as a letterspaced small-caps specimen caption, catalogue-plate style (the botanical art direction carried by typography, not borrowed boutique gloss).
