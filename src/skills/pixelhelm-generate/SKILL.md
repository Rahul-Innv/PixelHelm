# Generate UI candidates

Consume the ground context and token contract. Produce distinct candidates that
survive editing and preserve real data/state constraints. For redesigns include the
incumbent or bounded deltas. Emit candidates plus declared assumptions; judgment
belongs to `pixelhelm-judge`.
