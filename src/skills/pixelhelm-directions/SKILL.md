# Explore directions

Ground every direction in real constraints and data, vary one coherent visual thesis per
candidate, render a comparable matrix, and explain tradeoffs. The owner selects or
rejects the field; no direction silently becomes production code.

## Elicit first (REQUIRED, step 0)

Before writing the first direction name or thesis, ask the owner what the surface
should FEEL like: the wanted register in their own words, what is explicitly not
wanted, and the reference points they already like. Capture that answer verbatim into
the ground context every direction must serve, or record an explicit owner waiver in
the owner's own words. Never infer the answer from the profile alone and never ask
after the field is built. A run that did neither is a process defect and its run record
is refused. Rule: the loop leaf's gates-and-loop reference, section 0.
