# Specify video placement

Default to pre-rendered media with captions, poster, text fallback, lazy activation,
and performance budgets. A live avatar requires explicit server-token authority,
AI-not-human disclosure, cost controls, and a suitable marketing/sales context. Fail
closed when those conditions are absent.
